# Archived Xamarin projects

These are the original Fall 2017 Xamarin Android projects, kept for history.

| Folder | Notes |
|--------|--------|
| `EyeTrackWithGoogleVision/` | Google Mobile Vision API (deprecated). Not part of the active .NET 8 solution. |
| `MobileEyeTracker-OpenCV-Binding/` | Original OpenCV / JNI eye tracker that depended on the removed third-party `OpenCV.Binding` package. |

Active apps live under `src/EyeTracker` (Windows) and `src/MobileEyeTracker` (.NET 8 Android + CameraX / ML Kit).
